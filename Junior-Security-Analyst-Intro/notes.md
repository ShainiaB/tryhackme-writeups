# Junior Security Analyst Intro

Platform: TryHackMe  
Room: Junior Security Analyst Intro  

## Room Overview
This room simulates a day in the life of a Security Analyst and introduces the typical tasks and responsibilities they handle daily.

## Key Tasks Learned
- Monitoring security alerts and dashboards  
- Responding to phishing attempts  
- Checking user activity for anomalies  
- Documenting incidents and reporting to the team  

## Tools/Concepts Experienced
- Security Information and Event Management (SIEM) dashboards  
- Triage process for alerts  
- Basic incident reporting  

## Key Takeaways
- A Security Analyst is the first line of defense in a company’s cybersecurity operations  
- They must be detail-oriented and able to respond quickly to potential threats
