# Offensive Security Intro

Platform: TryHackMe  
Room: Offensive Security Intro  

## Room Overview
This room introduces offensive security concepts by allowing you to hack a website legally in a safe environment. It simulates the work of an ethical hacker.

## Key Concepts Learned
- Basics of ethical hacking  
- Understanding vulnerabilities in web applications  
- Safe, legal testing in a controlled environment  

## Tasks Experienced
- Identifying website weaknesses  
- Exploiting vulnerabilities safely  
- Documenting findings and responsible reporting  

## Key Takeaways
- Offensive security helps you understand how attackers think  
- Learning ethical hacking is essential for penetration testing  
- Hands-on practice improves both attack and defense skills
