## Room Overview

This room introduces the different roles within a Security Operations Center (SOC) and explains how security teams detect, investigate, and respond to cyber threats.

## Key Roles Covered

### SOC Analyst Level 1

* Monitors security alerts and dashboards
* Performs initial triage of alerts
* Escalates suspicious activity to higher-level analysts

### SOC Analyst Level 2

* Investigates alerts escalated from L1
* Performs deeper analysis of logs and network activity
* Determines if a real security incident has occurred

### SOC Analyst Level 3 / Threat Hunter

* Proactively hunts for threats within the network
* Looks for indicators of compromise that automated tools may miss

### SOC Engineer

* Builds and maintains security monitoring systems
* Configures SIEM tools and detection rules

### CERT / Incident Response Team

* Responds to major cybersecurity incidents
* Contains and mitigates attacks

### Penetration Tester

* Simulates attacks to find vulnerabilities before real attackers do

### GRC (Governance, Risk, Compliance)

* Ensures organizations follow security policies and regulations

### Threat Researcher

* Studies malware and hacker tactics
* Provides threat intelligence to improve defenses

## Key Takeaways

* Security teams have multiple specialized roles
* SOC analysts are often the entry point into cybersecurity
* Security operations rely on monitoring, investigation, and response
