# Defensive Security Intro

Platform: TryHackMe  
Room: Defensive Security Intro  

## Room Overview
This room introduces defensive security concepts by having you protect a simulated company (FakeBank) from an ongoing cyber attack.

## Key Concepts Learned
- Basics of defensive security and protecting systems  
- Monitoring and detecting suspicious activity  
- Responding to attacks in a controlled environment  

## Tasks Experienced
- Observing attack indicators  
- Using defensive tools to stop threats  
- Reporting findings and mitigation steps  

## Key Takeaways
- Defensive security is all about **preventing, detecting, and responding** to attacks  
- Hands-on practice is crucial for understanding real-world security operations  
- Entry-level defensive skills are essential for SOC and cybercrime roles
